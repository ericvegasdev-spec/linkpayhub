Questions

How does this actually work?
Your Mac runs Claude Code in a terminal, waiting. Your iPhone sends iMessages to itself (routed to the Mac). A small script on the Mac watches for those messages and feeds them to Claude. Claude does the work, texts you back. A Siri shortcut reads the reply out loud through your AirPods. All the setup takes ~30 minutes once.
Does this work without an iPhone?
No. This specific setup uses iMessage + iPhone Shortcuts. Android/Windows versions aren't covered in this guide — that's a different product.
Do I need to be a developer?
You need to already use Claude Code. Beyond that, the guide is copy-paste — no writing code, just running commands we wrote for you.
What if my Mac goes to sleep?
The guide has a full chapter on preventing Mac sleep — three settings for any Mac, plus an extra step for closed-lid MacBooks using the free Amphetamine app.
Will Claude still ask me to approve things while I'm away?
Only for commands you haven't pre-approved. Chapter 1.6 gives you a starting settings.json block that covers the common stuff. As you work, you add patterns once and they never prompt again.
