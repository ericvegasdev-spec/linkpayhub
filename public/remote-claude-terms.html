What's supported (and what's not)

The bridge shipped in this product forwards plain text iMessages to Claude Code. That's the core, tested path.

Not supported in v1:

  • Voice memos — audio isn't transcribed; the bridge skips it
  • Photos — image attachments aren't forwarded to Claude
  • Videos — not forwarded, and Claude Code doesn't natively process video
  • Files (PDFs, docs, CSVs) — attachments aren't forwarded
  • Stickers, tapbacks, reactions — no useful content for Claude
  • iMessage apps (Apple Pay, location pins, contact cards) — not supported

Extending the bridge to handle more content types (images, PDFs, voice transcription) is technically possible and may be released as a future v2 upgrade — but that upgrade is not included in this purchase. The scope here is text in → Claude working → text out.
